# Лабораторная работа №2  
## Анализ ассоциативных правил на датасете покупок


Цель работы: исследование методов анализа ассоциативных правил.

Постановка задачи:

1. Загрузить датасет из репозитория (например, kaggle.com или аналогичных платформ). Данные должны представлять собой информацию о купленных вместе товарах .

2. Привести описание данных из датасета: график вывода длин транзакций, список уникальных товаров и др. 

3. Алгоритм Apriori: выполнить анализ ассоциативных правил при помощи алгоритма Apriori с изначальными условиями в соответствии с вариантом задания. Проанализировать полученные результаты, выделив полезные и тривиальные правила, и оценив значение достоверности, лифта правил. Провести оценку влияния параметров алгоритма на получаемые правила (на количество правил и метрики).

4. Алгоритм FPG: провести анализ правил, используя алгоритм FPG. В отчете привести правила, получившиеся в результате использования данного алгоритма.

5. Алгоритмически определить минимальные значения поддержки для составления правил из 1, 2, и т.д. объектов в одном из алгоритмов.

6. Последовательно меняя параметры (значения поддержки и достоверности) одного из алгоритмов получить наборы ассоциативных правил. Сделать выводы на основе проведенных экспериментов.

7. Проанализировать получающийся в результате работы программы граф. Объяснить, какую информацию можно из него извлечь.

8. Предложить и реализовать свой способ визуализации ассоциативных правил и метрик.

## Анализ данных
Датасет: Количество строк: 9835. Количество столбцов: 33 (Item(s) + 32 товара). Пропуски означают отсутствие товара в транзакции.

Распределение длин транзакций: 
Гистограмма показала, что большинство покупок содержат 2–5 товаров. Транзакции более 10 товаров встречаются редко, а покупки с 20+ товарами практически отсутствуют. Это отражает повседневные, небольшие покупки клиентов.

Уникальные товары: Всего обнаружено 169 уникальных продуктов, включая молочные изделия, мясные продукты, напитки и бытовые товары.

## Подготовка данных

Таблица с транзакциями была преобразована в список списков, где каждая транзакция представлена списком товаров без пустых значений. Для алгоритмов Apriori и FP-Growth применялся One-hot encoding с помощью TransactionEncoder. В результате была получена бинарная матрица размером 9835×169, где значение True означает покупку соответствующего товара в данной транзакции.

## Ход работы

Для поиска часто встречающихся наборов товаров использовались алгоритмы FP-Growth и Apriori. Начальные параметры для обоих алгоритмов: поддержка 0.03 и достоверность 0.3. С помощью функции association_rules были построены правила зависимости между товарами с указанием метрик confidence и lift. В обоих алгоритмах доминирующими оказались товары «whole milk», «yogurt», «tropical fruit», «other vegetables» и «rolls/buns». FP-Growth выявил больше правил, включая менее устойчивые сочетания, тогда как Apriori фиксировал только наиболее стабильные паттерны.

Для визуализации топ-10 популярных товаров использовалась горизонтальная столбчатая диаграмма по уровню поддержки. Для анализа силы правил строилась диаграмма достоверности (confidence), где наиболее сильные связи наблюдались у пар «root vegetables — other vegetables», «whipped/sour cream — whole milk» и «root vegetables — whole milk».

Для более наглядного представления ассоциативных правил был построен сетевой граф с помощью networkx, где вершины соответствуют товарам, а рёбра отражают вероятность совместной покупки (confidence). В центре графа находился «whole milk», вокруг которого сгруппированы наиболее часто покупаемые вместе продукты.

Эксперименты с параметрами min_support и confidence показали, что при min_support = 0.02 и confidence = 0.3 алгоритм генерирует максимум правил (37), а увеличение порогов резко сокращает их количество. Анализ частоты наборов товаров по размеру показал, что одиночные товары встречаются чаще всего (средняя поддержка 6.2%), наборы из двух товаров встречаются реже (средняя поддержка 2.9%), а комбинации из трёх товаров встречаются ещё реже (средняя поддержка 2.3%).

## Заключение

Работа показала, что алгоритмы Apriori и FP-Growth позволяют выявить устойчивые паттерны покупок и зависимости между товарами. FP-Growth демонстрирует большую чувствительность к редким сочетаниям, тогда как Apriori фиксирует только наиболее устойчивые правила. Визуализация в виде столбчатых графиков и сетевых графов позволяет наглядно анализировать популярность товаров и силу ассоциаций. Параметры min_support и confidence существенно влияют на количество обнаруживаемых правил, что важно учитывать при практическом применении. Анализ размеров наборов товаров подтвердил закономерность: чем больше товаров в наборе, тем реже они встречаются вместе.
